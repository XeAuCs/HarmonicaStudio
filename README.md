# 口琴工坊 · Harmonica Studio

一个在 Windows 本机运行的 MIDI 工具：选取主旋律、简化多音、在音符图中修谱，导出单旋律 MIDI、AutoHotkey v2 脚本和试听 WAV。

当前版本：**1.4.9**。包含钢琴音名与按键文字对齐修复、统一便携目录，以及测试和成品检查通过后才更新程序的打包流程。

旋律处理新增“连续旋律（兼顾前后音）”和可选的乐句八度适配：完整模式的“曲谱 → 调音”中选择后重新生成。声部推荐使用真实的音符重叠时间、覆盖情况、音程连续性等特征；连续旋律会比较候选路线，减少长音被伴奏打断。默认仍为长音保护，新模式请结合具体编曲对比试听。

“超出音域时，允许按乐句调整八度”默认关闭。开启后按明显休止近似划分乐句，整句升降八度；会改变部分乐句间的高低关系，过宽且没有休止的乐句仍可能丢音。结果摘要显示调整和丢音数量，鼠标悬停可看提取时的调整时间范围；完整记录保存在工程和转换报告中。后续编辑不会重新套用八度适配。命令行使用 `--mode continuous --phrase-octave`。

默认开启“跳过长空白”：音符之间超过 3 秒的休止缩短为 0.6 秒，保留长音和正常停顿。电脑试听、手机遥控、导出的 MIDI 和游戏演奏采用相同时间安排；在“设置”中关闭即可恢复原停顿。原始音符与编辑时间轴保持不变，播放线只在被缩短的空白处加快通过，反复导出不会继续缩短。

## 直接使用

双击工程根目录的 **口琴工坊.lnk** 或 **启动口琴工坊.cmd**，也可打开 `app/HarmonicaStudio/HarmonicaStudio.exe`。便携版已包含运行环境，不需要安装 Python、Qt 或 AutoHotkey。移动或分享时只需复制整个 `app/HarmonicaStudio` 文件夹，再运行其中的 EXE；不需要携带开发项目。个人曲库、设置和编辑恢复记录随文件夹一起移动。

成品目录固定为：`HarmonicaStudio.exe`、`_internal`（运行依赖）、`samples`（运行曲库）、`data`（设置、自动保存和导出）。默认曲库与数据始终位于 EXE 旁边，不依赖父目录名称或启动位置。开发源码仍位于根目录 `src`；根目录 `samples` 只作为源码运行曲库和首次打包的种子资料，修改它不会自动改变已发布程序的曲库。

1. 点击“曲库”选歌，或打开、拖入自己的 MIDI。
2. 只想选歌试听时，点击右上角“设置”，勾选“精简模式”并保存：选歌后自动提取并生成，默认 1 倍速、自动调整八度。调音与编辑工具会收起；切回完整界面时，当前工程和已有修改仍在。
3. 需要修谱时，在“设置”中取消勾选精简模式并保存。在声部列表确认旋律，调整调音参数，点击“生成曲谱”进入“编辑与试听”。
4. 拖动音符改位置与音高，拉右边缘改时长，双击空白添加；选中后按 Delete 删除。支持撤销、重做。移动和拉伸按 0.05 秒网格吸附，会拒绝重叠音符。纵轴显示钢琴黑白键；“音域 − / +”调整纵向范围，“适配音域”让音符落入视野，也可按住 Ctrl+Shift 滚动鼠标滚轮缩放音域。
   音符方块内的 Z、X、C、V 等字母表示演奏按键，固定居中；↑ / ↓ 表示高 / 低八度，♯ 表示升半音。短音符放不下完整文字时省略标注，鼠标悬停仍可查看完整按键、音高及起止时间。
   紧邻的同音音符分成独立方块：例如 C C C 表示连续按三次 C。方块间的细缝仅用于区分边界，不会给音乐增加停顿。极短音符在缩小视图时会变窄，可放大查看。
5. 点击时间刻度或拖动进度条定位，再点“试听”。播放线保持在谱面中间，音符和时间尺平滑向左移动；歌曲开头和结尾的空白让游标也能居中。支持暂停后继续，停止归零。显示位置使用实际音频位置定期校正。试听采用合成音色，与脚本使用同一份按键时间表；编辑时停止旧试听，重新试听会先生成修改后的结果。
6. 点击“保存工程”保存 `.hstudio` 文件。工程包含完整音符与原始来源信息，之后不需要原 MIDI 就能打开继续修改。修改还会自动暂存，重新打开程序后可点“恢复上次编辑”。
7. 如使用“演奏”，切到游戏口琴界面后按 F6，3 秒后开始；F6 停止归零，F8 退出。切换窗口自动停止。“结束演奏”和关闭程序会请求脚本先松开按键再退出。

## 手机扫码遥控

1. 手机与电脑连接同一个局域网（电脑使用网线也可以），点击右上角“手机遥控”。
   窗口默认显示随主题变化的四色渐变“线条码”，内部图形和大小定位框均为圆角；可切换黑白“标准码”。装饰位于二维码净空之外，两种样式连接地址相同。右上角“设置”中的主题变化也会同步到已打开的二维码窗口。
2. 用手机扫码，在浏览器中打开页面。电脑有多个网络地址时，选择与手机 Wi-Fi 对应的地址；不要选 VPN 或虚拟网卡。也可以复制完整连接地址到手机浏览器。
3. 在手机曲库中选歌，电脑会自动读取和准备曲谱。页面同步电脑主题、歌曲、忙碌状态与播放进度。
4. “电脑试听”支持播放、暂停、继续、停止和拖动进度；声音从电脑播放，手机不接收音频。
   上方音符图显示当前曲谱，中央指示线固定，音符随音乐向左移动；暂停时停住，拖动进度时跳到对应位置。手机音符时长与电脑实际导出的试听、游戏按键时间表一致。
5. “游戏演奏”支持开始、停止和查看进度。先在电脑进入游戏口琴界面，再在手机点开始，3 秒后演奏。窗口失焦会停止并松开按键；保留电脑上的 F6 开始/停止与 F8 退出。游戏演奏暂不支持暂停或跳转。
6. “收起”只隐藏二维码，遥控继续可用；“关闭遥控”或退出程序会停止网页服务。重新开启时旧连接凭证失效，需要重新扫码。

不需要云服务器、账号或公网端口映射。电脑本身临时运行一个小型 HTTP 服务，默认端口 47638，被占用时自动选择空闲端口；只有主动开启时才监听。页面、二维码和曲库都在本机处理。持有完整二维码的人可以控制本工具，请只在可信局域网中使用。

如果连接不上：确认不是访客 Wi-Fi、路由器没有启用设备隔离，关闭手机移动数据后重试，并在 Windows 防火墙提示中允许本工具访问专用网络。浏览器内存保存当前连接，关闭标签页后可能需要重新扫码。电脑必须保持开机且程序运行。

手机指令沿用同一个软件键鼠演奏器，仍有游戏规则与检测风险；局域网控制不改变该风险。尚未验证真实手机与游戏内逐音响应。

## 曲库与外观设置

默认曲库是 EXE 旁边的 `samples`（本项目成品为 `app/HarmonicaStudio/samples`）。把 `.mid`、`.midi`、`.kar` 或 `.rmi` 文件放进这个文件夹，程序便会自动发现；增加、删除文件时会刷新菜单。只扫描文件夹当前这一层，扩展名不区分大小写。菜单中的“打开曲库文件夹”和“刷新曲库”可直接使用。程序目录内的自定义曲库保存为相对路径，可以随目录移动；外部曲库仍按用户指定的绝对路径访问。

在“设置”中可以指定自己的曲库文件夹，或切换“暖纸·朱砂、雾绿·松石、灰蓝·靛墨、素绢·梅紫”四套主题。选择主题会即时预览；点击保存后保留，取消则恢复原主题和设置。

“跳过长空白”在完整和精简模式下均生效。判断的是前一个音结束到后一个音开始之间的无声时间，恰好 3 秒不缩短；歌曲开头的空白仍由原来的“去掉开头空白”选项控制。修改此设置会停止当前试听或演奏，下次试听、重新导出或手机点演奏时生成新结果。旧导出文件不会被覆盖。音符图显示原谱秒数，播放进度显示实际时长；曲谱上方会提示共缩短了多少秒空白。

当前曲库包含《欢乐颂》《小星星》《友谊地久天长》《绿袖子》《奇异恩典》《斯卡布罗集市》《春日影》《未闻花名》《念张师》《得吃的小曲》《喀秋莎》，以及《中国人会飞》《太阳照常升起》的片段版，共 13 首。其中《春日影》先下载公开的 `.sequence` 曲谱，再转换成标准 MIDI；原始资料和来源说明均保留在 `samples`。来源和编配署名见 `samples/来源说明.md`。

`catalog.json` 只是可选的曲名、时长与选轨资料，不是导入白名单。无需修改它就能加歌。只有文件 SHA-256 与目录记录相符时才使用附加资料和选轨预设；同名文件被替换后，会重新按普通 MIDI 处理，避免套用旧曲谱的声部编号。

每次导出生成独立目录，不覆盖已有作品；配置和日志保存在 EXE 旁边的 `data`。当程序目录只读时，可设置环境变量 `HARMONICA_STUDIO_HOME` 显式指定外部可写位置，此时该外部数据不随程序移动。

自动暂存位于成品的 `data/autosave.hstudio`。切换文档前，尚未手动保存的工程另存于其 `data/recovery`，可通过“打开工程”找回。删除所有音符后仍可保存空工程，重新添加音符后再试听、导出。源码运行使用根目录 `data`，与便携版数据分开。

完整界面分为“曲谱”和“编辑与试听”。转换设置只在重新从 MIDI 生成时生效；编辑页的时间轴以秒表示，保留 MIDI 原有变速形成的时间位置。谱面与实际音频之间按相邻音符起点连续换算，松键间隔内也保持滚动；最后一个音符结束位置同样对齐。反复导出不会累加这段补偿。精简模式只改变操作界面，不会删除工程中的音符或撤销记录。

## 功能与限制

- 支持 SMF 格式 0/1 和 RIFF RMID，按完整速度表换算节奏，排除打击乐。
- 自动声部推荐；按轨道与通道手动选择，避免将同轨多乐器混淆。
- 最高音模式使用 25 毫秒分组；连贯模式另抑制被长旋律音覆盖的低音伴奏。这是启发式处理，不能保证准确识别所有作品的主旋律。
- 速度 0.25–2 倍，手动移调 ±24 半音，可自动按整八度适配 C3–C6# 的按键模型。
- 按键采用固定物理间隔，普通速度下保留音符起点；极密音符可能延后，报告会记录。
- 输入上限 20 MB、1024 轨、10 万音符，试听上限 20 分钟；暂不支持格式 2 和 SMPTE 计时。
- 不识别音频和谱图；不还原 MIDI 弯音、踏板、音色和力度表现。
- 游戏输入兼容性和实际游戏音色尚未实测。官方禁用列表包含自动脚本/鼠标宏，可能导致账号处罚；大厅和自定义房间不能视为豁免。本项目不实现反检测、内存读写或游戏注入。

## 工程结构

开发和 agent 测试可使用 `launch.py diagnose` 测量加载、曲库刷新、自动保存及取消场景；支持真实 Qt 响应探针、可取消后台延迟、总超时和 JSON 报告。具体命令与指标解释见 [性能诊断](docs/diagnostics.md)。测试使用临时合成数据，不读取个人曲库或发送游戏按键。

```text
src/harmonica_studio/
  midi.py          MIDI 读取、速度换算与写出
  models.py        转换选项和校验
  melody.py        声部推荐、旋律简化、移调
  rests.py         从原谱派生长休止缩短后的播放音符
  schedule.py      音高映射与按键时序
  preview.py       时间表校验与 WAV 合成
  service.py       原子导出与转换报告
  project.py       可独立保存的工程格式与校验
  editor.py        可编辑音符图、历史记录与定位
  playback.py      试听和演奏器生命周期
  transport.py     音频时间映射、进度插值与位置校正
  gui.py           Qt 桌面界面
  theme.py         四套纸色主题与共享调色板
  preferences.py   曲库路径、主题、精简模式和长空白偏好
  settings_ui.py   设置对话框与主题预览
  storage.py       配置和轮转日志
  diagnostics.py   无按键输入的成品检查
  library.py       本地曲库扫描与可选资料校验
  assets/          播放器模板与原创口琴图标
tests/             单元与转换集成测试
scripts/           测试与打包脚本
samples/           13 首 MIDI、原始曲谱资料、可选目录与来源说明
third_party/       AutoHotkey 官方运行程序及许可证
app/               可直接运行的 Windows 便携版
data/exports/      每次转换的完整导出目录
```

## 开发

架构与维护边界见 [应用架构说明](docs/architecture.md)。桌面和手机通过独立适配器调用同一个应用控制层；工程版本、后台任务和播放状态集中管理，工程与编辑器共享音符校验。

Windows 10（1903 或更新）/11 x64，Python 3.10+（本次使用 3.12.14，在 Windows 11 验证）。建议独立虚拟环境。

```powershell
python -m venv .venv
.venv\Scripts\python -m pip install -r requirements-build.txt
.venv\Scripts\python -m pip install -e .
.venv\Scripts\python launch.py gui
.\scripts\test.ps1 -Python .venv\Scripts\python.exe
.\scripts\build.ps1 -Version 1.4.7
```

开发依赖来自 PyPI，运行及转换过程不联网。核心转换仅依赖标准库，GUI 使用 PySide6 Essentials。依赖版本锁定在 `requirements-build.txt`。

也可双击根目录的 **打包.cmd**，输入版本号；直接回车使用当前版本。脚本自动选择项目的 `.venv`，无需手动激活。命令行省略 `-Version` 可按当前版本重新打包，仍支持 `-Python` 和 `-DistPath`。

`scripts/build.ps1` 先检查目标程序已关闭，按需同步源码、包元数据及说明中的版本号，然后运行完整测试、生成便携版并执行成品检查。全部通过才安装到目标目录。更新保留现有 `samples`、`data` 和其他用户文件；已删除的示例曲目不会重新加入。失败时保留旧版 EXE，源码版本号保留为本次指定值，修复后可直接重试。构建缓存与自测数据放在同一个临时目录，完成或失败后自动清理；报告与截图保存在 `verification`，详细日志固定写入 `verification/build.log`。控制台只显示四步进度。`scripts/smoke.ps1` 仍可单独复验，并支持 `-ExecutablePath`。

打包配置在 `HarmonicaStudio.spec`，通过相对工程路径定位资源。Qt 使用 Windows 自带 ICU；配置会排除部分 Python 发行版中同名但接口不兼容的 ICU，避免成品出现 DLL 入口缺失。

原始图标为 `src/harmonica_studio/assets/studio.svg`；构建脚本会运行 `scripts/make_icon.py` 重新生成 PNG 和包含 16–256 像素尺寸的 ICO，并嵌入程序。构建完成后运行 `scripts/create_shortcut.ps1` 可在工程目录生成带图标的快捷方式。

播放动画按约 60 Hz 更新，使用单调时钟对音频位置插值，再由播放器反馈校正；进度条以浮点位置绘制，避免整数像素步进影响观感。这只影响显示，导出的音符时间与按键编排不因动画频率改变。

## 命令行

```powershell
python launch.py inspect samples/欢乐颂.mid
python launch.py convert samples/欢乐颂.mid --out data/exports
python launch.py convert song.mid --track 1 --channel 2 --speed 0.8 --transpose 0
```

轨道索引从 0 开始，通道参数从 1 开始。`--mode highest` 切换最高音模式；`--keep-silence` 保留开头等待；`--no-auto-octave` 禁用自动八度。

每个导出目录包含 `口琴单旋律.mid`、`演奏脚本.ahk`、`试听.wav`、`音符.json`、`按键时间表.json`、`转换报告.json` 和 `工程.hstudio`。报告保留原文件 SHA-256、所选声部、转换参数、丢音数与时序调整数；工程保存编排前的音符时间，其余文件使用实际按键时间。

## 检查与排错

```powershell
.\scripts\smoke.ps1
```

此检查使用离屏界面，从示例导入、编辑、保存恢复、后台转换一直验证到 AHK 语法，生成检查报告和界面图；试听交互使用静音替身，不会向游戏发送输入。普通错误会在界面提示，详情见 `data/logs/studio.log`。损坏文件或取消操作不会留下半成品导出目录。

`scripts/test.ps1` 在安装 PySide6 时也会运行 Qt 鼠标、键盘交互测试；没有 Qt 时这些测试明确标为跳过，核心转换、工程和音频控制测试仍可运行。

P1/P2 架构改造已通过 180 项单元与交互测试，无跳过或已知失败；包括不启动 Qt 的控制层测试。完整记录见 `verification/p1-p2-acceptance.md`；上述测试不代表游戏内实测。

便携目录迁移记录见 `verification/portable-layout-acceptance.md`。旧运行数据经逐文件核对后迁入成品 `data`；历史构建副本不作为当前程序使用。
